# Render deployment guide

This project is ready to deploy as a Node.js web service on Render.

## 1. Push the project to GitHub

Commit these files and push your repo.

## 2. Create a new Render Web Service

- Go to https://render.com
- Create a new Web Service
- Connect your GitHub repo
- Use the default Node environment
- Render will read the included `render.yaml` file

## 3. Add the required environment variables

In Render dashboard, set these values before deployment:

- `DB_HOST`
- `DB_PORT`
- `DB_USER`
- `DB_PASSWORD`
- `DB_NAME`
- `JWT_SECRET`
- `APP_BASE_URL` = your live domain URL
- `NODE_ENV` = production

## 4. Database

This app requires MySQL. Use an external MySQL service or a Render-managed database if available for your account.

Then import the schema:

```bash
mysql -u <user> -p < schema.sql
```

## 5. Seed admin user

After the app is running, run:

```bash
npm run seed
```

## 6. Live URL

The final URL will be generated by Render, for example:

```text
https://takeoff-driver-onboarding.onrender.com
```

Or you can connect your own custom domain.
